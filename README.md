# evidence-gate

给"生成层"加裁判的那一层。不是打分，是问：**这条主张的依据，在扰动下还站得住吗。**

eda-spine 的四段骨架（search / prove / perturb / cover）原样保留，只是把"门"从
网表等价性换成了对**预测型主张**的审查。oracle 不是湿实验——湿实验一次不可逆，
不能拿来做门；门用的是**可复现的扰动**：划分方式、特征置换、标签置换。

## 四关

    G1 复现门   同一流程再跑一遍，数字必须逐位相同，否则后面全不算
    G2 扰动门   逐特征置换 + 骨架块置换 + 标签置换（标签置换是阴性对照，
                不塌说明整条管线是坏的，不是这条主张是好的）
    G3 分布门   同一主张换划分方式：随机划分 vs 未见骨架（scaffold）。
                高 AUC + 换划分就塌 = 记忆，不是预测
    G4 覆盖门   扰动空间里真跑过几类，没跑过的显式列出来（不假装覆盖）

判决与分数无关，与"分数是怎么来的"有关。G2 里掉得最多的那一组，就是分数真正的来源。

## 实跑（2026-10-02，本机）

    主张 A  描述符 + 骨架身份 -> 活性   AUC 0.703  ->  REJECT
            G2 掉最多的是 scaffold_block 0.116（分数骑在骨架身份上，不是化学上）
            G3 随机 0.703 vs 未见骨架 0.603，gap 0.10
    主张 B  仅描述符 -> 活性            AUC 0.589  ->  PASS
            G3 随机 0.589 vs 未见骨架 0.593，gap -0.004

门驳回了分数高的那条，放过了分数低的那条。这正是要的：**排的是可信度，不是分数。**
batch 2 条主张 1.9 秒。

## 跑

    python gate.py

依赖：标准库。（本机 numpy.random 在子进程里 MemoryError，所以没走 numpy。）
